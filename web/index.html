Detail spoje

    API URL / JSON

    Odkaz vrátí aktuální data pro stejnou zastávku, stanoviště, linku a směr jako tabule. Přebírá také volbu minulého odjezdu.

    Otevřít JSON ↗

    Budoucí odjezdy jsou v poli departures, volitelný minulý odjezd v previous_departures. Odkaz vždy vrací čerstvou odpověď, nikoli uložený snímek tabule.

    Pokud je v adrese localhost nebo 127.0.0.1, pro přístup z jiného zařízení ho nahraďte dostupnou adresou svého serveru.

    Home Assistant

    Integrace IDS JMK nabídne nastavení serveru a výběr zastávky v průvodci. Níže je alternativní REST senzor a karta flex-table-card.

    Jak nainstalovat integraci

    Zkopírujte složku custom_components/ids_jmk z projektu do složky config/custom_components svého Home Assistantu a restartujte ho.

    Potom otevřete Nastavení → Zařízení a služby → Přidat integraci → IDS JMK. Průvodce nabídne adresu serveru, vyhledání zastávky, stanoviště, linku a směr. Pro HACS přidejte GitHub repozitář projektu jako vlastní repozitář typu Integration.

    Pokud je tu localhost, nahraďte ho IP adresou serveru.

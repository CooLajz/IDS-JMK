# IDS JMK Parser

Parser jízdních řádů a realtime IDS JMK přímo v Home Assistant OS. Obsahuje pouze API, bez samostatného webu. Podporuje 64bitové Raspberry Pi (ARM64) a virtuály či počítače s AMD64.

Po spuštění propojte aplikaci s [integrací IDS JMK](https://github.com/CooLajz/IDS-JMK/blob/main/docs/home-assistant.md). Integraci a odjezdovou kartu instalujte samostatně přes HACS nebo ručně.

Podrobný postup a nastavení najdete na kartě **Dokumentace** aplikace.

Data poskytuje KORDIS JMK pod licencí [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Projekt je nezávislý a není oficiální aplikací KORDIS JMK.

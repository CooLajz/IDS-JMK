# Grafika IDS JMK API server

Schválený zdrojový návrh: `ids-jmk-api-server-concept.png`. Vytvořeno vestavěným nástrojem imagegen; červená šalina, tmavomodré nápisy „IDS JMK“ a „API server“ na bílém pozadí. Jde o grafiku nezávislého projektu, nikoli oficiální logo dopravního systému.

Distribuované PNG zachovávají celý schválený návrh:

- `custom_components/ids_jmk/brand/icon.png` a `logo.png`: 256 × 256 px.
- `custom_components/ids_jmk/brand/icon@2x.png` a `logo@2x.png`: 512 × 512 px.
- `home-assistant/ids_jmk/icon.png`: 128 × 128 px.
- `home-assistant/ids_jmk/logo.png`: 256 × 256 px.

Bílé pozadí zachovává čitelnost i v tmavém motivu. Při úpravách zachovejte názvy distribuovaných souborů a aktualizujte obě sady. Pokyny k zobrazení naleznete v [dokumentaci Home Assistantu](../../docs/home-assistant.md#ikona-integrace-a-aplikace).

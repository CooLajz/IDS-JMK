## Co je nového

- **Mapa vehyklů jako třetí karta Home Assistantu.** V editoru vyberte připojení IDS JMK, jednu nebo více linek a u každé jeden nebo oba směry. Mapa zobrazuje vozidla po celé trase jejich aktuálního spoje, nezávisle na počtu odjezdů a zastávce tabule.
- **Bez entit pro jednotlivá vozidla.** Data procházejí přes přihlášené připojení k Home Assistantu. Prohlížeč nepotřebuje přímý přístup k API a souřadnice se nezapisují do historie entit.
- **Detail spoje.** Kliknutím na vozidlo zobrazíte jeho cíl, čas polohy, dostupné zpoždění a zastávky. Mapa se přizpůsobí celé trase. Čára je pouze orientační spojnice zastávek; zdroj GTFS neobsahuje přesnou geometrii tras.
- **Nové mapové API.** Katalog linek a směrů a filtrované aktuální polohy respektují kalendář spoje, provozní den i stáří dat. Zkrácené spoje jsou zahrnuty podle směru GTFS. Při zastarání poloh nebo chybě spojení karta značky skryje a zobrazí vysvětlení.

## Aktualizace

Pro mapovou kartu **aktualizujte API server i integraci IDS JMK na verzi 0.1.5**, restartujte Home Assistant a obnovte dashboard. Poté přidejte kartu **IDS JMK — Mapa vehyklů**. Nový server ani další instance nejsou potřeba.

- Samostatný Docker/Portainer: použijte `ghcr.io/coolajz/ids-jmk-api:0.1.5`, případně web `ghcr.io/coolajz/ids-jmk-web:0.1.5`, stáhněte nové obrazy a znovu nasaďte Stack.
- Aplikace v HA OS: aktualizujte IDS JMK Parser na `0.1.5` (`ghcr.io/coolajz/ids-jmk-ha:0.1.5`). Integraci aktualizujte samostatně přes HACS nebo přiložený ZIP.
- Zachovejte celý datový svazek včetně `instance-id` a statistik. Realtime musí být zapnutý; výchozí nastavení zůstává vypnuté.

Mapový podklad OpenStreetMap vyžaduje připojení prohlížeče k internetu. Karta obnovuje polohy každých 30 sekund; server dodržuje svůj interval stahování realtime.

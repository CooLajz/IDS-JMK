## Co je nového

- **Jeden zdroj, více odjezdových tabulí.** Adresu API nastavte jednou a další zastávky, linky a směry přidávejte pod tímto zdrojem. Každý další server má vlastní tabule a statistiky.
- **18 kumulativních statistických senzorů.** Celková stažení a přijaté bajty, zvlášť statistiky GTFS a realtime a počty požadavků, chyb a odpovědí API. Čítače se denně nenulují; denní nebo měsíční přehled vytvořte pomocí Utility Meter. Data zůstávají v databázi serveru i po restartu.
- **Samostatné statistické API.** Endpoint `/api/v1/statistics/cumulative` poskytuje kumulativní hodnoty bez načítání grafů. Integrace jej obnovuje jednou za minutu za každý zdroj, nezávisle na počtu tabulí.
- **Ikony dopravy a barevné rozlišení směrů na mapě.** Vozidla rozlišují druh dopravy a směr spoje.

- **Mapa vehyklů jako třetí karta Home Assistantu.** V editoru vyberte připojení IDS JMK, jednu nebo více linek a u každé jeden nebo oba směry. Mapa zobrazuje vozidla po celé trase jejich aktuálního spoje, nezávisle na počtu odjezdů a zastávce tabule.
- **Bez entit pro jednotlivá vozidla.** Data procházejí přes přihlášené připojení k Home Assistantu. Prohlížeč nepotřebuje přímý přístup k API a souřadnice se nezapisují do historie entit.
- **Trvalé zastávky podle linky a směru.** U každé linky můžete zapnout zastávky všech jejích variant, i když právě žádné vozidlo nejede. Zastávky jsou výraznější a při přiblížení mají názvy. API nově nabízí `/api/v1/map/stops`.
- **Nastavitelná obnova a automatický Přehled.** Interval nastavíte v kartě (výchozí 30 sekund). Přepínač Přehled si pamatuje volbu po obnovení stránky a automaticky zahrnuje všechna vozidla i zapnuté zastávky. Při menším počtu autobusů zůstávají ve výřezu zastávky celé trasy.
- **Detail spoje.** Kliknutím na vozidlo zobrazíte jeho cíl, čas polohy, dostupné zpoždění a zastávky. Kliknutím do volné mapy detail zavřete. Čáry se zobrazují pouze v detailu. Čára je pouze orientační spojnice zastávek; zdroj GTFS neobsahuje přesnou geometrii tras.
- **Nové mapové API.** Katalog linek a směrů a filtrované aktuální polohy respektují kalendář spoje, provozní den i stáří dat. Zkrácené spoje jsou zahrnuty podle směru GTFS. Při zastarání poloh nebo chybě spojení karta značky skryje a zobrazí vysvětlení.

## Aktualizace

Toto vydání **0.1.5 bylo aktualizováno o podporu zastávek a opravy mapy**. Pokud již používáte dřívější sestavení 0.1.5, stáhněte obrazy znovu a integraci přeinstalujte z aktuálního ZIPu nebo přes opětovné stažení v HACS. Samotné číslo verze se nemění; běžné oznámení nové verze se proto nemusí objevit. Zachovejte data a restartujte parser i Home Assistant.

Pro nové zdroje, statistiky a mapovou kartu **aktualizujte API server i integraci IDS JMK na verzi 0.1.5**, restartujte Home Assistant a obnovte dashboard. Poté přidejte kartu **IDS JMK — Mapa vehyklů**. Nový server ani další instance nejsou potřeba.

- Samostatný Docker/Portainer: použijte `ghcr.io/coolajz/ids-jmk-api:0.1.5`, případně web `ghcr.io/coolajz/ids-jmk-web:0.1.5`, stáhněte nové obrazy a znovu nasaďte Stack.
- Aplikace v HA OS: aktualizujte IDS JMK Parser na `0.1.5` (`ghcr.io/coolajz/ids-jmk-ha:0.1.5`). Integraci aktualizujte samostatně přes HACS nebo přiložený ZIP.
- Zachovejte celý datový svazek včetně `instance-id` a statistik. Realtime musí být zapnutý; výchozí nastavení zůstává vypnuté.

Mapový podklad OpenStreetMap vyžaduje připojení prohlížeče k internetu. Karta obnovuje polohy podle nastaveného intervalu (výchozí 30 sekund); server dodržuje svůj interval stahování realtime.

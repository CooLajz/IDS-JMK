## Co je nového

- **Realtime podle potřeby klientů.** Server sdílí jedno stahování mezi klienty a po pěti minutách bez požadavku na realtime přejde do nečinnosti. Parametr `realtime=false` umožňuje použít pouze jízdní řád. `REALTIME_IDLE_TIMEOUT_SECONDS=0` ponechá stahování nepřetržité ve všech variantách Docker Compose.
- **Obnovování tabulí podle viditelnosti v Home Assistantu.** Odjezdové a výlukové karty udržují obnovování při zobrazení. Pro automatizace a jiné karty zapněte u tabule přepínač „Průběžné obnovování“. Výchozí režim je podle viditelnosti, také u existujících tabulí. Ruční aktualizace entity zůstává dostupná.
- **Odolnější stahování.** Souběžné požadavky sdílejí aktualizaci, chyby prodlužují prodlevu a HTTP `Retry-After` se respektuje i po restartu. Jedna odpověď API používá jeden realtime snapshot.
- **Přesnější zacházení s chybnými daty.** Neplatný čas vozidla již nezpůsobí chybu celé odpovědi API a rozporná zastávka vozidla se nepoužije pro odhad zpoždění.
- **Aktuální detail mapy.** Čas polohy a zpoždění v otevřeném detailu se obnovují spolu s vozidly bez opakovaného stahování trasy. Vlastní odhad zpoždění je výslovně označený.
- **Vylepšené karty a web.** Editor mapy zachovává rozpracovaný vstup při aktualizacích HA. Upozornění zachovávají bezpečné formátování a lépe se seskupují. Grafy statistik umožňují pohodlnější výběr hodnot. Web nabízí trasu zastávek i bez aktuální polohy vozidla.
- **Rozšířené kontroly před vydáním.** CI zahrnuje testy obnovování podle viditelnosti a regresní scénáře pro časy vozidel, konflikty zastávek a obnovování detailu mapy.

## Aktualizace

Aktualizujte API/parser, web a integraci IDS JMK na **0.1.6**. Po aktualizaci integrace restartujte Home Assistant a obnovte dashboard.

- Docker/Portainer: použijte obrazy `ghcr.io/coolajz/ids-jmk-api:0.1.6` a případně `ghcr.io/coolajz/ids-jmk-web:0.1.6`.
- HA OS: aktualizujte aplikaci IDS JMK Parser na **0.1.6** a integraci samostatně přes HACS nebo přiložený ZIP.
- Zachovejte datový svazek, identitu instance a statistiky. Realtime je nadále nutné výslovně povolit.
- Pokud odjezdy používáte v automatizacích bez zobrazené vlastní IDS JMK karty, zapněte přepínač **Průběžné obnovování** u příslušné tabule.

Polohy a vlastní odhady závisejí na dostupnosti a stáří zdrojových dat. Čára trasy zůstává orientační spojnicí zastávek.
